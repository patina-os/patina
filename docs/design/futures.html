patina21 · redesign, round 1

Eight futures for patina21

Eight complete directions for the mark, the type, the colours and the Plasma desktop, from cockpit calm and a rain-soaked city to a desert at dusk and a terminal made of falling code. Each one is buildable today: fonts from Debian's archive, Plasma set through its own tools, artwork as generated SVG. Pick one, or the parts you want to combine, and round 2 refines it.

Decision · 22 Oct 2026Datum, with the Sora ExtraBold wordmark and fluorescent coral as the accent. The other seven stay on this page as candidates for additional themes.

The same in all four

The name stays patina21, lowercase, with the superscript ²¹ in the typeset wordmark. Icon, colours and type are new.

Every face is a Debian package, named under each specimen. This page loads the same faces from Google Fonts for preview; 3270 is embedded from Debian's own package.

Colours are a base16 palette with the desktop accent in base0E, so today's renderer reads them unchanged.

Each case marks its work: Data a setting or theme file, Template a new renderer template, Cost a dependency or trade-off.

Palette · base16

How it ships

  • DataPalette, wallpaper, fonts-oxanium and fonts-ibm-plex, all from Debian main.
  • TemplateChamfered windows need an Aurorae decoration: SVG frames that KWin already has an engine for, generated from the palette.
  • TemplateThe chamfered panel and menus need a Plasma desktop theme, also SVG. A second template to maintain.
  • CostAurorae draws through QML and feels heavier than Breeze on low-end ARM boards. The glow is painted into the decoration's shadow, not a live effect.

  • CostCyberpunk is the look that dates fastest of the four.

Decision

        
Datum, with Sora ExtraBold for the wordmark and fluorescent coral as the accent. The other directions are kept as candidates for additional themes.

        
My read before the decision

        
If one of these had to ship in the next release, it would be Perigee. It needs no new templates, reads well all day, and its sci-fi comes from type and light rather than costume, so it ages slowly.

        
Datum, the mix of Perigee and the ASCII idea, keeps Perigee's low cost and adds the strongest system idea of all eight: the mark is plain text, so one file serves the terminal and the screens.
Sirocco is a close second: no new templates either, and warm where almost every Linux desktop is cold. Canopy is the friendliest of the seven.
Sodium, Phosphor and Cascade are the most memorable, but each brings a template to maintain and trades some readability for mood. Nacre's ring mark, Cascade's ASCII text mark and Canopy's weather widget could join any route.
